# Changelog

All notable changes to Squoosh Desktop. Versions follow [Semantic Versioning](https://semver.org).

## [0.1.1] - 2026-09-24

### Added

- The interface is translated into 17 languages: English, French, German, Spanish, Italian, Portuguese (Brazil), Dutch, Polish, Russian, Ukrainian, Turkish, Indonesian, Vietnamese, Chinese (Simplified and Traditional), Japanese and Korean. Codec settings and error messages are translated too.
- The app follows the system language. You can change it from the language menu on the welcome screen and in the image list, or with the `SQUOOSH_LANG` environment variable. The choice is remembered.
- Chinese, Japanese, Korean and Vietnamese are displayed with a font already installed on the system.
- The Windows installer is available in 12 languages, and the Linux desktop entry is translated.

### Changed

- The README and the documentation are in English, with screenshots.
- Button labels shrink to fit when a translation is long.

## [0.1.0] - 2026-09-23

First release: native port of Squoosh for Debian 13, Arch Linux and Windows 10/11, with MozJPEG, OxiPNG, WebP and AVIF encoders, side-by-side comparison, resize, palette reduction and batch conversion.
